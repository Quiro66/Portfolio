## 📖 Descripción del Portfolio

Mi portfolio personal muestra mi experiencia profesional, educación, proyectos destacados y habilidades técnicas. Incluye:

- **Home**: Presentación personal con animaciones y enlaces a redes sociales
- **About**: Información detallada sobre mi perfil, habilidades técnicas y herramientas
- **Projects**: Proyectos destacados con descripciones y enlaces a repositorios
- **Resume**: Experiencia laboral y educación en formato timeline interactivo
- **Contact**: Información de contacto con enlaces directos a LinkedIn, GitHub, teléfono y email

### ✨ Características

- **🌍 Traducciones i18n**: Soporte completo para español e inglés
- **📱 Fully Responsive**: Diseño optimizado para móvil, tablet y escritorio
- **🎨 Diseño Moderno**: Tema oscuro con efectos de partículas y animaciones
- **⚡ Performance**: Optimizado para carga rápida y SEO
- **🔗 Enlaces Directos**: Redirecciones a todas mis redes sociales y contacto

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando:

- **React.js** - Framework principal
- **React Router** - Navegación entre páginas
- **React Bootstrap** - Componentes UI responsivos
- **i18next** - Sistema de traducciones
- **React Vertical Timeline** - Timeline interactivo para experiencia/educación
- **React Icons** - Iconos para redes sociales y herramientas
- **Particle.js** - Efectos de partículas en el fondo

## � Instalación y Configuración

### Prerrequisitos

- Node.js instalado
- npm o yarn instalado
- Git instalado

### Pasos de Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Quiro66/Portfolio.git
   cd Portfolio
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm start
   ```

4. **Abrir en el navegador:**
   ```
   http://localhost:3000
   ```

### Construcción para Producción

```bash
npm run build
```

## 🎨 Personalización

Para personalizar este portfolio con tu información:

1. **Editar información personal:**
   - Modifica `src/i18n.js` para cambiar textos en español e inglés
   - Actualiza `src/components/Home/Home.js` para cambiar nombre y redes sociales
   - Edita `src/components/Resume/ResumeNew.js` para experiencia y educación

2. **Cambiar colores y estilos:**
   - Modifica `src/style.css` para personalizar el diseño
   - Cambia variables CSS en `src/App.css`

3. **Agregar proyectos:**
   - Edita `src/components/Projects/Projects.js` para agregar nuevos proyectos
   - Agrega imágenes en `src/Assets/Projects/`
